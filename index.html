Git Data API

Push satu file langsung ke repo GitHub

Isi token, tujuan repo, dan pilih file — semuanya dikirim langsung dari browser ke GitHub lewat blob → tree → commit → ref, persis seperti git push di terminal.

Detail push

Butuh token dengan izin Contents: Read and write (fine-grained) atau scope repo (classic). Buat token di sini. Token hanya dipakai di browser kamu, tidak pernah dikirim ke tempat lain selain GitHub. Kalau mau pakai fitur "buat repo baru" di akun pribadi (bukan organisasi), GitHub mengharuskan classic token dengan scope repo — token fine-grained nggak bisa membuat repo baru di akun pribadi (fine-grained baru bisa untuk repo organisasi, dengan izin Administration: Read and write).

Berjalan sepenuhnya di browser kamu — tidak ada server perantara. Permintaan dikirim langsung ke api.github.com memakai token yang kamu masukkan. File .zip otomatis dibongkar di browser (pakai JSZip, tidak diupload ke mana pun) lalu tiap isinya di-push jadi satu commit — bisa dimatikan lewat checkbox kalau maunya file .zip-nya sendiri yang diupload. Untuk file/zip besar (puluhan MB), proses hashing & ekstraksi bisa memakan waktu beberapa detik.
